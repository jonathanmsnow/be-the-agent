# Be The Agent

Be The Agent is an exploratory learning environment that targets professional software engineers who regularly use agentic coding tools such as Claude Code or GitHub Copilot. The learner needs to decide what tools to call, how to manage their context, and effectively respond to a user just as an LLM does inside the agent harness.

The project is designed as an open educational resource that is open for extension and remixing in accordance with the [license](./License).
